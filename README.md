# 자원·에너지의 효율적 활용

과학 탐구 활동(교과서 94~95쪽) "자원과 에너지의 효율적인 이용 방법은?"을 위한 학생용 웹사이트입니다.

- `index.html`: 마을 지도와 8개 장소(우리 집, 아파트, 학교, 큰 건물, 주택가 지붕, 가전 매장과 수리점, 재활용 센터, 숲과 목공소)
- `village.js`: 도트 그림을 그리는 코드
- `water-*.html`, `forest-*.html`, `mineral-*.html`, `energy-*.html`: 주제 카드 24개

사이트 주소: https://leafyellow42.github.io/energyefficiency_52sci/
